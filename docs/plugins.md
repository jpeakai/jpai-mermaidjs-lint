# Writing plugins and local rules

This guide now lives on the docs site, split by what you want to do:

- [Write a local rule](https://jpeakai.github.io/jpai-mermaidjs-lint/guides/local-rule/) in one file in your project.
- [Publish a plugin package](https://jpeakai.github.io/jpai-mermaidjs-lint/guides/plugin-package/) to share rules between projects.
- [The plugin model](https://jpeakai.github.io/jpai-mermaidjs-lint/concepts/plugin-model/) explains discovery, loading and conflicts.
- [Plugin API](https://jpeakai.github.io/jpai-mermaidjs-lint/reference/plugin-api/) lists every field of the contract.

The pages are authored in `docs-site/docs/` in this repository.
The decision behind the plugin contract is [MJL-0007](../adrs/0007-plugins-follow-the-prose-gates-contract.md).
